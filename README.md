# KBN InfraQuality Testing Services

Responsive React website for KBN InfraQuality Testing Services, Channarayapatna, Karnataka.

## Live website

https://deepukbn.github.io/kbninfraquality-testing-services/

Company profile, services, staff, named clients, and certification details are based on the supplied 12-page company brochure. The website uses the official logo and selected lab, field, and team photographs embedded in that brochure. The brochure does not provide named project case studies or a formal vision/mission statement, so these are not presented as company facts.

Certification standards shown on the site are transcribed from the brochure.

The contact form opens the visitor's default email application with the enquiry details addressed to the listed company email. No backend submission service is configured.

## Run locally

```sh
npm install
npm run dev
```

## Validate and build

```sh
npm run lint
npm run build
```

The production site is written to `dist/` for static hosting.
